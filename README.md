# AircrewCareer — Re-imagined Aviation Landing Page

A glassmorphic, aviation-themed landing page prototype for [AircrewCareer.com](https://aircrewcareer.com/) designed with an interactive 3-mode atmospheric sky engine (**Daylight Sky**, **Evening Sunset Dusk**, and **Night Flight Cockpit/Milky Way**).

## Features
- **Atmospheric Sky Themes:**
  - 🌅 **Evening Sky (Dusk):** Golden hour amber-orange horizon transitioning into indigo twilight with warm glass reflections.
  - 🌌 **Night Flight:** Starry Milky Way and night wing seat view with midnight glass styling.
  - ☀️ **Daylight Sky:** High-altitude clear troposphere blue canvas with passing aircraft contrails.
- **Glassmorphism Styling:** Multi-layered frosted glass (`backdrop-filter: blur(24px)`), soft inset borders, and flight-dispatch telemetry.
- **Responsive Layout:** Designed for mobile, tablet, and desktop screens.
- **Static Deployment:** Ready for zero-dependency hosting on GitHub Pages.
